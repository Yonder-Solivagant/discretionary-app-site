Discretionary

个人自用的投资资讯邮件归档助手 · Personal email archiving tool

这个应用做什么

Discretionary 是一个运行在开发者个人电脑上的脚本工具。它通过 Google Gmail API 以只读方式读取开发者本人 Gmail 收件箱中、由开发者自己订阅的资讯邮件， 把这些邮件的正文另存为本地 Markdown 文本文件，便于长期检索与复盘。

数据访问范围： https://www.googleapis.com/auth/gmail.readonly（只读，不发送、不删除、不修改、不打标签）。

谁在使用

本应用为单一用户的私人工具，未面向公众分发，也没有任何服务端、数据库或第三方托管的 数据存储。授权对象仅为开发者本人的 Google 账户。

In short (English)

Discretionary is a personal, locally-run script that reads the developer's own Gmail inbox in read-only mode (gmail.readonly) and saves the body of newsletters the developer subscribed to into local Markdown files. There is no server, no database, no third-party data sharing, and no distribution to other users.
